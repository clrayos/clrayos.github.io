# amphotobooth.com

Main site for amphotobooth.com. For now it only forwards visitors to the
archivedmoments_ photobooth app.

| Address | Goes to |
|---|---|
| amphotobooth.com | amphotobooth.com/go |
| amphotobooth.com/go | the am.go app (repository `go`) |
| amphotobooth.com/go_ | amphotobooth.com/go (old link, kept so shared links still work) |

When the physical photobooth site is ready, replace `index.html` with it.
Keep the `go_/` folder so old links keep working.

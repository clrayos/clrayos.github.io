# amphotobooth.com

Main site for amphotobooth.com. For now it only forwards visitors to the
archivedmoments_ photobooth app.

| Address | Goes to |
|---|---|
| amphotobooth.com | amphotobooth.com/go_ |
| amphotobooth.com/go | amphotobooth.com/go_ |
| amphotobooth.com/go_ | the am.go_ app (repository `go_`) |

When the physical photobooth site is ready, replace `index.html` with it.
Keep the `go/` folder so the short link keeps working.
